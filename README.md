# 🧬 DNA Nucleotide Counter

A simple Python bioinformatics project that counts the four nucleotides (A, T, G and C) present in a DNA sequence.

## Features
- Counts A, T, G and C
- Accepts uppercase or lowercase DNA sequences
- Removes spaces and line breaks
- Validates the DNA sequence
- Displays total nucleotide count

## Requirements
- Python 3.x

## How to Run

```bash
python dna_counter.py
```

Enter a DNA sequence when prompted.

## Example

### Input
```text
ATGCGATACGTT
```

### Output
```text
DNA Nucleotide Count
--------------------
A: 3
T: 3
G: 3
C: 2
Total nucleotides: 11
```

## Bioinformatics Application

Nucleotide counting is a basic sequence-analysis task used to determine DNA nucleotide composition and as an initial step in further sequence analysis.
